# 多GOP无丢包学习实验

短检查模式：False；随机初始化；已完成10轮、1060次更新。
训练106个GOP；验证22个GOP。最佳验证MSE=0.01874418，出现在第10轮。

每轮对训练与验证集合均使用舍入量化，以所有有效RGB像素汇总MSE，再换算PSNR。updates.csv记录加噪量化训练时更新前指标；epochs.csv记录轮末舍入评估。
验证集参与模型选择，不能作为独立测试集。同一视频的时间隔离不消除场景相关性。
预处理采用全画面缩放补边；量化范围、MoE配置等为学习配置，尚非论文完整复现。本实验不包含丢包、恢复网络、MS-SSIM或实际比特率评估。
检查点保存优化器及随机状态，但此脚本尚无自动续训入口；不要用单GOP续训脚本加载。
