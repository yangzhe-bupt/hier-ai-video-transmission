一、项目定位与版本边界

项目基于《Conquering High Packet-Loss Erasure: MoE Swin Transformer-Based Video Semantic Communication》的思路进行复现与改进。
当前实现以4帧GOP为单位，采用空间Swin、时空Swin、公共/个体双分支、3-bit特征量化和MoE，并在主时空编解码器中加入残差组。
这是基于论文思路的复现与改进实现，不能表述为论文源码或全部细节严格对齐的版本。

当前模型名称：residual_branches_moe_3bit
参数量：6,881,214，约688.1万。
当前训练：REDS多视频、无丢包、端到端训练。
当前前向不包含：丢包模拟、丢失特征恢复、后置图像增强。
仓库内存在相关历史实验代码，不代表本轮训练已启用它们。

二、整体流程与发送端/接收端边界

发送端：
4帧RGB视频
  → 逐帧空间编码
  → 时空编码（3D Swin-MoE + 阶段内残差组）
  → 得到时空特征 F
  → 提取公共特征 C
  → 计算个体残差 R = F - C（C沿时间维广播）
  → 压缩个体残差为个体特征 I
  → C与I分别进行3-bit量化。

接收端：
接收两路量化特征
  → 个体特征上采样恢复
  → 与公共特征相加
  → 时空解码（3D Swin-MoE + 阶段内残差组）
  → 逐帧空间解码
  → 输出4帧RGB重建视频。

当前量化张量直接送达接收端，没有经过真实网络链路。
残差组连接仅存在于单个阶段内部，不跨越发送/接收边界，不传递额外高分辨率跳连特征。

三、张量布局与尺寸表

视频张量布局：[B,T,C,H,W]。
B为GOP批量，T固定4，C为通道数，H/W为高宽。
以下尺寸对应当前256×256训练裁剪；不等同于已验证720P推理。

位置                         张量尺寸
输入                         [B,4,3,256,256]
空间编码Stage1               [B,4,24,128,128]
空间编码Stage2               [B,4,48,64,64]
空间编码Stage3               [B,4,72,32,32]
时空编码Stage4               [B,4,96,16,16]
时空编码Stage5，特征F        [B,4,120,8,8]
公共特征C                    [B,1,120,8,8]
个体残差R，压缩前            [B,4,120,8,8]
个体特征I，压缩后            [B,4,144,4,4]
接收端个体特征恢复后         [B,4,120,8,8]
公共/个体融合后              [B,4,120,8,8]
时空解码Stage5               [B,4,96,16,16]
时空解码Stage4               [B,4,72,32,32]
空间解码中间尺度             [B,4,48,64,64]、[B,4,24,128,128]
最终重建                     [B,4,3,256,256]

调用逐帧二维模块时临时转换为[B×T,C,H,W]，随后恢复时间维；该转换不执行帧平均。

四、空间编解码器

文件：step/06_spatial_codec.py
编码：2×2 Patch Embedding → 24通道Swin块对 → Patch Merging → 48通道Swin块对 → Patch Merging → 72通道Swin块对。
每阶段包含非移位/移位窗口块，空间窗口4×4，注意力头数3。
Patch Merging拼接相邻空间位置，经LayerNorm和线性投影降低分辨率、调整通道。
空间Swin使用普通MLP，没有替换为MoE。

解码：72→48→24→3通道，逐级Swin处理并上采样。
Patch Expansion采用线性映射与PixelShuffle。
最终Sigmoid将输出RGB限制到[0,1]。
注意：最终图像Sigmoid与量化前的激活映射是不同位置。当前主模型没有在量化前增加tanh/sigmoid映射。

五、时空编解码器

文件：step/07_spatiotemporal_codec.py
主编码器两个阶段：72通道32×32 → 96通道16×16 → 120通道8×8。
时间维一直保持4；降采样只作用于空间。
每个主阶段两个3D Swin块，注意力窗口(T,H,W)=(4,4,4)，3个头。
两个块的移位分别为(0,0,0)和(0,2,2)，时间方向不移位。
窗口内最多64个时空位置，覆盖4帧；通过空间移位实现跨空间窗口信息交换。
解码器先在当前尺度处理，再空间上采样，恢复至72通道32×32。
当前没有显式光流、运动补偿或光流对齐模块，帧间关系由3D注意力学习。

六、残差组：当前结构扩展

文件：tools/37_temporal_restoration_variants.py、tools/40_residual_full_codec.py。
计算公式：G(x) = x + Conv2D_3×3(SwinPair(x))。
卷积按帧计算，跨帧建模仍来自内部3D Swin。
卷积权重及偏置零初始化，使组的初始映射接近恒等映射。

位置：时空编码Stage4(C=96)、Stage5(C=120)、时空解码Stage5(C=120)、Stage4(C=96)。
这是组级残差，叠加在Swin块本身已有的残差连接之外。
没有在公共分支或个体压缩/恢复块外额外套同样的组。
该设计是本项目的结构扩展，不应称为论文原样结构。

接口注意：AuxiliaryResidualGroup支持原stage逐块提取辅助损失的接口，组内aux求和，len保留原Swin块数，避免按包装器数量错误归一化。

七、公共/个体双分支

基础文件：step/08_feature_decomposition.py。
当前公共分支替换：step/12_model_variants.py中的Figure7CommonExtractor。

公共分支：
F[B,4,120,8,8] → 转为BCTHW布局 → Conv3d(kernel=(4,3,3), stride=(4,1,1), padding=(0,1,1)) → GELU → 1×1×1通道混合。
此时T=1，转为二维空间特征，经过公共残差细化：
S + Conv2d/GELU/Conv2d/GELU(S)，再恢复为C[B,1,120,8,8]。
公共表示通过训练学习，不是固定时间平均。

个体分支：
R_t = F_t - C。
R经Patch Merging与单个3D Swin-MoE压缩为I[B,4,144,4,4]。
接收端：单个3D Swin-MoE → Patch Expansion → [B,4,120,8,8]。
融合：F_hat_t = C_hat + IndividualUpsample(I_hat)_t。
公共特征通过广播与各帧相加。

当前没有独立性/解耦约束，公共/个体是结构性角色，不保证两路信息完全无冗余。

八、MoE机制

文件：step/11_moe_swin.py。
替换位置：3D Swin中的前馈MLP；不替换注意力模块。
每块4个专家、每位置Top-2选择。
专家结构：Linear(C,4C) → GELU → Linear(4C,C)。
路由器为不带bias的线性层，产生4个分数，Softmax后选Top-2，选中概率重新归一化后加权组合专家输出。
路由粒度为每个时空位置，不是整帧/整个GOP。

MoE(z) = Σ[e属于Top2(z)] w_e(z) E_e(z)。

MoE块数：时空编码器4 + 个体压缩1 + 个体恢复1 + 时空解码器4 = 10。
负载均衡辅助损失：E × Σ_e(f_e × p_e)，E=4；f_e为Top-K分配占比，p_e为筛选前平均路由概率。
完整模型按各模块实际块数加权汇总10块的平均辅助损失。
某个微批次未选中的专家可能没有梯度，这不自动意味着实现故障。

九、当前3-bit特征量化

文件：step/09_quantization_channel.py中的UniformQuantizer。
两路各自调用量化器，配置均为3-bit、[-1,1]、8个等级、码值0~7。
步长Δ = (1-(-1))/(8-1) = 2/7。

训练：
  x_c = clip(x,-1,1)
  x_tilde = x_c + ε，ε服从U(-Δ/2,Δ/2)。
训练不真实取整，使用噪声近似保持范围内可微；范围外裁剪有饱和问题。
加噪结果可能略超出[-1,1]。

验证/推理：
  q = round((x_c+1)/Δ)
  x_hat = -1 + q×Δ。
对称8级重建集合不包含精确零值。

量化针对传输特征，网络权重仍FP32。
主训练路径输出仍是浮点表示的离散级别，没有实际按3-bit打包发送。
工具中存在打包和LSQ/激活映射对照实验，但没有全部接入当前主训练路径。
当前不是LSQ，也不是tanh/sigmoid映射量化。

十、特征规模与码率边界

256×256裁剪、4帧GOP：
公共特征元素数 = 1×120×8×8 = 7680。
个体特征元素数 = 4×144×4×4 = 9216。
合计 = 16896。
维度比例 = 16896/(4×3×256×256) = 0.021484375。
假设每元素直接打包3bit，理想特征负载 = 50688bit/GOP = 6336byte/GOP。

这个计算不含分包头、冗余纠错、协议元数据和重传，没有经过实际链路测量；维度比例也不是完整压缩文件码率。
当前不能据此宣布达到720P、1Mbps或实时要求。

十一、REDS多视频训练

配置：
  Adam，学习率1e-4，FP32，seed=42。
  物理batch=4 GOP，梯度累积8次，有效batch=32 GOP。
  梯度范数裁剪上限1。
  每轮约188次参数更新，60轮约11280次。
  训练加量化噪声，验证真实舍入。
  当前无丢包、无后置增强、无时间一致性损失。

  import sys, importlib
  from pathlib import Path
  root = Path.cwd()
  sys.path[:0] = [str(root/'tools'), str(root/'step')]
  codec = importlib.import_module('40_residual_full_codec')

  reconstruction, auxiliary_loss, statistics = model(video)
  video/reconstruction：[B,4,3,256,256]。
  auxiliary_loss：可反向传播的标量。
  statistics：common/individual原始特征超出[-1,1]的比例，仅用于观察饱和。
  model.train()启用量化噪声，model.eval()启用真实舍入。
