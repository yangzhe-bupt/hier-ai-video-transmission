# 当前残差完整模型与REDS训练

当前模型：`residual_branches_moe_3bit`，6,881,214参数。空间Swin→时空Swin→公共/个体双分支→3-bit量化→特征融合→时空/空间解码。主时空编解码4个阶段增加残差组，3D Swin的MLP采用4专家、逐位置Top-2 MoE。详见[完整交接说明](模型代码交接说明_20261124.txt)。

这是论文思路的复现与扩展，不是全部细节严格对齐的原版。残差组为本项目扩展，REDS为替代数据。当前主线不启用丢包、特征恢复或后置增强，历史Stage II/增强代码保留但未自动接入主线。

## 环境与数据

在`论文复现`目录运行。建议Python 3.11，先安装适合设备的PyTorch，再安装requirements。已验证PyTorch 2.6.0+cu124、OpenCV 5.0.0和RTX 4060 Laptop 8GB。

数据集只提供[下载地址与校验说明](REDS数据集.md)，不上传数据或权重。将`train_sharp.zip`和`val_sharp.zip`放在同一个目录，无需解压。

```powershell
python -m pip install -r requirements.txt
$dataRoot = 'D:\Datasets\REDS' # 改成自己的数据目录

# 只检查数据，不构造优化器、不训练
python -u -B tools/41_train_reds_residual.py --data-root $dataRoot

# 全模型训练60轮，每轮2000/4000/6000个GOP显示进度，每轮验证并保存
python -u -B tools/43_reds_log_every2000gops.py --train --data-root $dataRoot --epochs 60
```

训练240段/6000 GOP，独立验证30段/750 GOP；GOP4，训练同组共享随机256裁剪，验证固定中心裁剪。物理batch=4、累积8次、有效batch=32，FP32，Adam学习率1e-4，梯度范数裁剪1，seed42。损失为MSE + 0.01×MoE_aux。每轮约188次参数更新。

训练量化：裁剪至[-1,1]后加U(-Δ/2,Δ/2)噪声，Δ=2/7。验证量化：真实舍入为0~7码值再反量化。网络权重仍FP32；主线没有实际比特分包发送，没有LSQ或额外tanh/sigmoid映射。最终图像Sigmoid与量化前映射是不同位置。

## 续训与文件

输出：`outputs/step41_reds_residual/<运行编号>/`。`last.pt`恢复完整轮次，`best.pt`按独立验证MSE选择；包含优化器/RNG。保留配置、数据清单、源码哈希/快照、history/result和曲线。仅加载自己生成的可信检查点。

```powershell
$last = Get-ChildItem 'outputs/step41_reds_residual/*/last.pt' -File |
    Sort-Object LastWriteTime -Descending | Select-Object -First 1
if (!$last) { throw '没有找到多视频last.pt，不自动从头训练。' }
$target = python -c "import sys,torch; print(torch.load(sys.argv[1],map_location='cpu',weights_only=False)['epoch']+30)" $last.FullName
if ($LASTEXITCODE -ne 0) { throw '检查点读取失败。' }
python -u -B tools/43_reds_log_every2000gops.py --train --data-root $dataRoot --resume $last.FullName --epochs $target
```

续训保持源码、数据位置/划分、关键配置一致。仓库更新后旧检查点可能无法通过严格源码哈希校验，应使用各运行的对应源码快照。Step40固定8GOP检查点不能直接作为Step41多视频续训检查点。

## 对照与已有证据

```powershell
# 需CUDA；验证前向/反向/确定性评估，不执行优化器更新
python -u -B tools/40_residual_full_codec.py --self-test
# 固定8训练GOP，三个模型从头拟合
python -u -B tools/40_residual_full_codec.py --train --data-root $dataRoot --steps 10000 --eval-every 500
```

| 固定8个训练GOP、10000次更新 | 最佳PSNR |
| --- | ---: |
| 残差组+双分支+普通MLP，不量化 | 28.393 dB |
| 残差组+双分支+MoE，不量化 | 28.932 dB |
| 残差组+双分支+MoE+3-bit量化 | 28.595 dB |

这些是单种子训练子集拟合结果，不是多视频独立验证成绩；参数/算力不同，不是等预算对照。多视频训练仍需验证泛化。当前256裁剪、无丢包，维度比例0.021484375不等于实际码率；尚未完成LPIPS、真实链路开销、720P持续24fps和抗丢包验收。
