一、目标与工作方式

每轮先解释结构、张量形状和代码，再由你在 VS Code 编写运行。代码需有详细注释。

本计划已核对方法和主要训练设置。尚未明确的实现细节必须继续查图、公式及引用资料，并记录假设。
Step04 已完成首轮结构核对；参数细化将贯穿后续步骤。

二、总体数据流
发送端：视频 GOP -> 三阶段空间 Swin 编码 -> 组合各帧特征 -> 3D Swin 时空编码（前馈层采用 MoE）-> 公共/个体特征提取 -> 量化 -> 交织 -> 分包 -> 丢包通道。
接收端：数据重组 -> 逆交织 -> 公共分支 2D CNN 恢复、个体分支 3D CNN 恢复 -> 个体上采样 -> 两分支相加 -> 时空解码 -> 分帧 -> 空间解码 -> 重建视频。
张量记法：项目一般采用 BTCHW；Conv3d 一般接收 BCTHW。每个边界都需明确转换。

三、15 个步骤

Step01：理解编解码接口【已完成】
文件：step/01_autoencoder.py
任务：随机视频 -> 轻量逐帧 Swin 编码器 -> CNN 解码器 -> MSE -> backward。
验收：输入/重建 [1,4,3,32,32]，特征 [1,4,24,8,8]，梯度有限。
设备：本机 CPU，无参数更新。

Step02：固定合成 GOP 训练、可视化与保存【已完成】
文件：step/02_train_single_gop.py
任务：学习 Adam 更新，在同一个移动红色方块 GOP 上训练 200 步。
结果：MSE 0.156539 -> 0.002146；位置、颜色可恢复，边缘仍模糊。
权重：outputs/step02/autoencoder.pt。
设备：小型训练，本机 CPU。

Step03：置零丢包基线【已完成】
文件：step/03_packet_loss.py
任务：加载 Step02 权重，16 个特征元素一包，总计 384 包；独立丢包，缺失置零。
结果（设定概率 / 实际丢包率 / MSE）：

25% / 22.9% / 0.012222
50% / 46.4% / 0.031185
90% / 92.4% / 0.136473
图片：outputs/step03_packet_loss.png。
说明：一次随机抽样的学习实验，包长单位为元素数；后续要与论文量化和传输单位对齐。

Step04：论文结构与配置核对【首轮已完成，细节持续补齐】
依据：图 4–8、第 IV 节、第 V-A 节、表 II。

逐项继续核实：窗口空间尺寸、注意力头数、专家数 m、top-Kr、路由和辅助损失细节、损失权重 alpha/beta/gamma、量化范围映射、训练轮数等。

Step05：真实视频读取与一致裁剪【下一步】
建议文件：step/05_video_dataset.py
任务：先读取一个真实 GOP；BGR 转 RGB；归一化到 [0,1]；正确组织 BTCHW；显示四帧顺序。
同一 GOP 使用相同裁剪位置，避免人为引入帧间跳动。论文 GOP=4，训练裁剪 256×256；本机接口可先用小尺寸。
验收：帧顺序、颜色、形状正确；路径可配置；按视频或原始序列划分数据。
设备：本机，无需训练。

Step06：三阶段空间 Swin 编解码器
建议文件：step/06_spatial_codec.py
任务：按图 5 实现 Patch Embedding、分层 Swin 和 Patch Merging；实现对应的空间解码。
编码空间尺寸依次约为 H/2、H/4、H/8；通道与深度参考表 II。
验收：每阶段尺寸/通道正确；前向反向检查通过；先在真实单 GOP 上检查能否过拟合。
设备：接口用本机；小规模训练提前提醒，优先 3090。
现有逐帧 Swin + CNN 保留为基线，单独管理新模型配置和检查点。

Step07：独立 3D Swin 时空编解码器
建议文件：step/07_spatiotemporal_codec.py
任务：按图 6 增加 Stage4/5；学习三维窗口划分、移位、相对位置及逆变换；接在空间编码之后。
论文时间窗口覆盖 GOP，即 n=4。先用普通前馈层验证 3D 主干，再在 Step11 替换为 MoE。
验收：完整 GOP 的时空尺寸追踪正确；窗口往返正确；梯度可传递。
设备：小张量本机；训练前提醒使用 3090。

Step08：可学习公共/个体特征提取及上采样
建议文件：step/08_feature_decomposition.py
任务：按图 7 用 3D 卷积把时间维压到 1，经激活、1×1×1 卷积和残差网络得到 Xc。
将 Xc 广播后从 Xst 中减去，残差进入个体特征提取器进一步压缩，接收端实现对应上采样。
验收：公共分支时间维=1，个体分支保持帧结构；通道、广播、上下采样一致；记录表示大小。
说明：已有时间均值+平均池化属于对照基线。下采样后的分解不要求无误差可逆。
设备：接口本机；学习参数训练前提醒使用 3090。

Step09：量化、交织、分包与通道
建议文件：step/09_quantization_channel.py
任务：对两分支实现量化与可逆交织；同步逆交织特征及 mask；对齐应用层分包与语义擦除模拟。
依据：论文使用 3-bit 量化。式 (16) 训练时 Q(X)=X+U(-1/2,1/2)，验证/测试使用取整。
继续核实数值范围、缩放与打包方式；加入噪声并不自动实现 3-bit 码字。不要将 float32 或 int8 存储直接等同于 3-bit 传输。
区分论文训练的元素擦除模拟与真实整包擦除。保留两种通道实现，对比结果注明模式。
验收：交织可逆；0%/100% 丢失正确；实际丢失比例可记录；真实位数、头部及量化元数据开销可追踪。
设备：接口本机，无需正式训练。

Step10：公共 2D / 个体 3D 双分支恢复
建议文件：step/10_branch_recovery.py
任务：按图 8 实现卷积恢复网络，以掩码筛选修复量并残差相加：Y_recovered=Y+M*F(Y)。
M=1 表示缺失。公共分支使用 2D CNN，个体分支使用 3D CNN。
按原图确认卷积层、激活和通道。先实现图中的 mask 乘法位置；额外将 mask 拼接输入属于另行实验。
验收：收到的位置保持原值；缺失位置可学习补全；无缺失时为恒等恢复；明确全缺失输入行为。
设备：接口本机；恢复训练在 Step13 统一执行，提前提醒。

Step11：在 3D Swin 中加入 MoE
建议文件：step/11_moe_swin.py
任务：在 Step07 的前馈位置接入路由器、m 个专家与 top-Kr 加权汇总，按引用方法实现辅助损失。
验收：输出形状正确；被选专家与路由参数获得预期梯度；统计专家使用、负载和参数量。
专家数、top-Kr 和辅助损失系数先查证，再决定配置；未给出的值标注假设。
设备：接口本机；正式学习在下一步，使用 3090 前提醒。

Step12：完整模型阶段 I——无丢包重建训练
建议文件：step/12_train_stage1.py
任务：整合空间/时空编解码、分解、MoE 和训练量化近似，按原图安排通道两端。
损失：式 (15)，LOSS1=alpha*MSE(原视频,重建视频)+beta*MoE辅助损失。
数据：Vimeo-90k，GOP=4，同 GOP 一致随机裁剪 256×256，像素 [0,1]。
论文 Adam 学习率 1e-4，batch size 32，单 RTX A6000。3090 先用 small 模型和小 batch 短跑测显存；这些是适配选择，记录与论文默认 mid 的差别。
验收：独立验证集、日志、最佳模型与完整续训状态；记录训练配置、种子、数据划分和模型版本。
设备：正式训练，提前提醒并准备 3090。

Step13：完整模型阶段 II——冻结编码器的抗丢包训练
建议文件：step/13_train_stage2.py
任务：加载阶段 I 权重，冻结发送端编码相关参数，明确模块边界；训练恢复模块和接收端。
损失：式 (17)，LOSS2=LOSS1+gamma*[MSE(Xi,Yir)+MSE(Xc,Ycr)]。
每个 GOP 独立从训练丢包率数组选择条件，论文示例 [0.0,0.3,0.6,0.9]。
验收：冻结参数不更新；无丢包与高丢包均评估；保留最佳权重、优化器和随机状态。特征损失比较的是原图规定的对应节点。
设备：正式训练，提前提醒使用 3090。

Step14：模型规模、正式指标和通信预算评估
建议文件：step/14_evaluate.py
任务：按表 II 配置 small/mid/large；统计参数、速度和显存；需要不同权重时提前安排训练。
论文默认 mid，CBR=0.0078。CBR 按式 (14) 是两分支特征总维度/源数据维度，另行报告量化后的实际比特预算。
测试 HEVC Class A/B 与 UVG；评估 PSNR、MS-SSIM；明确分辨率处理、像素范围、指标实现、聚合方式和随机种子。
协议分析设定包括 49 字节头部、155520 字节待传语义数据；只用于原文对应实验，不能直接套到任意分辨率。
多丢包率、多种子重复；输出均值/波动、曲线、可视化。
说明：当前核对到的轻量化包括表 II 的模型规模配置，不预设额外剪枝或蒸馏算法。
设备：统一设备推理；另训规模模型提前提醒用 3090。

Step15：消融、对照与复现报告
产物：实验表格、曲线、复现差异表、运行说明。
任务：按论文检查无恢复、无 MoE、无公共/个体分解等消融及模型规模比较；交织作为单独对照。
先建立同预算内部对照；原文对手包括 MDVSC、H.264/H.265+LDPC，逐项记录是否具备公平复现条件。
验收：控制数据划分、训练条件、通信预算及丢包模型；结构变化通常需要重训，单纯推理关模块作为另一类实验注明。
区分合成学习实验、小规模验证和正式指标。90% 丢包下摘要指标只有设置对齐时才比较。
