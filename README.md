# PING-III 弱网自适应视频传输

| 目录 | 内容 |
| --- | --- |
| [论文复现](论文复现/) | 基于 MSTVSC 的现有实现、运行说明和实验记录。后续弱网自适应传输在这里集成。 |
| [第一次尝试](第一次尝试/) | 旧版 Swin/CNN、分层 UDP 传输、信道回放和历次实验材料，原目录结构保留。 |

本学期的交付目标是用同一条链路演示编码、传输、反馈、发包策略切换、缺失恢复和视频重建。论文提供编解码和抗丢包恢复的技术基线。自适应的工程对照使用相同模型权重下的固定传输策略。

## 运行入口

- 新主线的安装、数据与快速检查见 [论文复现说明](论文复现/README.md)。
- 复跑早期实现时，从 [第一次尝试](第一次尝试/README.md) 目录执行其中的命令。
